@startuml
title Создание проекта — упрощённая последовательность
skinparam shadowing false

actor "Пользователь" as U
participant "UserDashboardWindow\n(панель клиента)" as Dash
participant "ProjectsControl\n(вкладка Projects)" as View
participant "ProjectsViewModel" as VM
participant "DAL (UnitOfWork/Repos)" as DAL
database "PostgreSQL (core)" as DB

U -> Dash : выбирает вкладку "Projects"
Dash -> View : инициализирует вкладку/контрол
View -> VM : создаёт VM и запускает загрузку списка
VM -> DAL : запросить проекты (с учётом фильтров)
DAL -> DB : SELECT / user_get_*()
DB --> DAL : список проектов
DAL --> VM : данные
VM --> View : коллекция проектов для отображения
View --> U : показывает карточки проектов\n+ элементы управления (Add/Edit/Delete/Filter)

U -> View : нажимает "Add"
View -> VM : открыть форму создания
VM --> View : форма становится видимой (поля ввода)

U -> View : заполняет поля и нажимает "Save"
View -> VM : сохранить проект
VM -> DAL : создать проект
DAL -> DB : CALL core.user_create_project(...)
DB --> DAL : OK/ошибка
DAL --> VM : результат
VM -> DAL : обновить список проектов
DAL -> DB : SELECT / user_get_*()
DB --> DAL : обновлённый список
DAL --> VM : данные
VM --> View : обновление карточек
View --> U : новая карточка появляется / показ ошибки

@enduml

Пользователь в панели клиента выбирает вкладку Projects — вкладка инициализируется, запускается загрузка проектов из БД, и на экране появляются карточки проектов с кнопками управления (добавить/редактировать/удалить/фильтрация). Затем пользователь нажимает Add — открывается форма создания проекта и отображаются поля ввода. После заполнения полей пользователь нажимает Save — система отправляет команду в БД на создание проекта, затем обновляет список и перерисовывает карточки так, чтобы новый проект появился в интерфейсе (или показывает сообщение об ошибке, если операция не удалась).
